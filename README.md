_# 🐾 SOPA - Sistema de Organização e Proteção Animal

Sistema desenvolvido para auxiliar ONGs e protetores independentes na gestão de animais resgatados, adoções, tratamentos médicos e controle de voluntários.

---

## 🛠️ Tecnologias Utilizadas

* .NET 9.0** (ou versão atual da sua solution)
* Blazor WebAssembly** (Frontend)
* ASP.NET Core Web API** (Backend)
* Entity Framework Core** (ORM)
* Bootstrap 5 & Bootstrap Icons** (Estilização)

---

## 💻 Pré-requisitos e Extensões

Antes de abrir o projeto pela primeira vez, certifique-se de ter instalado em sua máquina:

1. .NET SDK** (versão correspondente ao projeto - ex: .NET 8 ou 9).
2. IDE de sua preferência**: Visual Studio 2022 ou Visual Studio Code.
3. Extensões recomendadas (caso use VS Code):**
    *C#* (ms-dotnettools.csharp)
    *C# Dev Kit* (ms-dotnettools.csdevkit)
    *ASP.NET Core Snippets*
